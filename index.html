How updates work

OBS loads the hosted widget once, then the widget requests fresh data from Leetify at your selected interval. No local app or hosted polling worker is required.

Open source

The source code is available on GitHub if you prefer to review or run the overlay locally. This project was quickly vibe-coded in my spare time, so if you encounter any issues, please feel free to open an issue on GitHub.
